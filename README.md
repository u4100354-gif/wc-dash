# WC DASH — Забег до туалета

## 6.6.0 · Движения на коте и правильные ботинки

[Играть на GitHub Pages](https://u4100354-gif.github.io/wc-dash/?v=6.6.0)

Браузерный раннер на Three.js: три полосы, прыжки между крышами поездов,
движущиеся потоки в канализации и один важный финиш.

| Уровень | Длина | Маршрут |
| --- | --- | --- |
| 01 · Солнечное депо | 720 м | Электрички, экспрессы, грузовые вагоны |
| 02 · Большой коллектор | 1 800 м | Насосные станции, каскады потоков, открытые участки |
| 03 · Портовый экспресс | 900 м | Набережная, краны, контейнерные дворы |
| 04 · Зелёная линия | 1 080 м | Сады, перголы, прыжки и подкаты |
| 05 · Центральный вокзал | 1 260 м | Город, часовые башни, встречные составы |
| ∞ · Марафон | Без конца | Генерируемые парк, рынок и вокзал |

В 6.6.0 Денис и Марс получили согласованные движения езды: три стадии галопа,
перестроения, отталкивание, группировку в воздухе, подготовку к приземлению,
амортизацию, низкое пригибание, посадку, сход и реакцию на удар. При действии
вниз всадник прижимается к спине кота; человеческий кувырок на коте не включается.
Четыре лапы кота имеют суставы и постановку на опору. Спина и таз всадника
используют общую точку посадки и общий ритм движения.

Бонус ботинок окрашивает обувь и её высокие манжеты. Ноги, таз и ягодицы остаются
в цвете штанов выбранного скина, включая высокий прыжок и окончание бонуса.

Уровни доступны сразу. Победа предлагает следующий конечный маршрут; прогресс
сохраняется вместе с прежним кошельком, котами, улучшениями и скинами.

С версии 6.5.0 финиш использует общую временную шкалу прыжка, разворота и посадки на
уменьшенный WC. Полёт KFC поднят с 6,1 до 10,6 м; ближний свод канализации
убирается на время полёта и спуска камеры. Портретная камера держит
трассу на центральной оси и сохраняет Дениса в кадре во всех трёх полосах.

Окружение за трассой дополнено дальними кварталами, холмами, портом с водой и
катерами, насосными резервуарами, садами, парковками и вокзальными зданиями.

## Управление

| Действие | Клавиатура | Телефон |
| --- | --- | --- |
| Полоса | ← / →, A / D | Свайп вбок |
| Прыжок | ↑ / W / пробел | Свайп вверх |
| Кувырок | ↓ / S | Свайп вниз |
| Кот | C / кнопка кота | Кнопка / двойной тап |
| Пауза | Esc / кнопка Ⅱ | Кнопка Ⅱ |

Смена полосы во время кувырка включает боковой перекат. Прыжок прерывает
кувырок. Свайп вниз в воздухе ускоряет снижение. Активные ботинки собирают
предметы под прыжком в той же полосе до приземления, включая момент истечения
бонуса. Крылышки дают примерно 140 м полёта; другие бонусы на это время ждут.

Стоп-кадр для разработки: **Д / L** или **▣**. Мышь вращает камеру, ПКМ сдвигает,
колесо приближает; WASD перемещают, Q/E меняют высоту. Точка / Ю — один кадр,
H скрывает панель. HUD и игра остаются в кадре без затемнения.

## Локальный запуск

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/`. Сборка и установка npm не нужны. Three.js
0.187.0 включён в проект с MIT-лицензией. Нужен HTTP: ES-модули не запускаются
обычным открытием `index.html` через `file://`.

```powershell
node --test tests/*.test.cjs
```

Тесты проверяют физику и проходимость, сохранения, анимационные позы, геометрию,
проекции камеры и построение сцен. Проверки сцен используют настоящий Three.js
с адаптером вместо GPU-рендерера; они не заменяют осмотр WebGL на телефоне.

Все модели и анимации созданы для проекта. Редактируемые GLB лежат в
`assets/models/`; команды экспорта, Blender и лицензии — в `docs/ASSETS.md`.
Фотографии кота хранятся на локальном диске D и не публикуются.
